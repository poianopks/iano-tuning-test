# 피아노숨결 홈페이지

피아노 조율사를 위한 반응형 한 페이지 홈페이지입니다. 별도 설치 없이 `index.html`을 브라우저로 열어 미리 볼 수 있습니다.

## 연락처 바꾸기

1. `index.html`을 엽니다.
2. `010-8756-8740`을 새 전화번호로 모두 바꿉니다. 링크의 `tel:010-8756-8740`도 함께 변경합니다.
3. `hello@example.com`을 실제 이메일로 바꿉니다. 링크의 `mailto:hello@example.com`도 함께 변경합니다.
4. 필요하면 `운영 시간 · 평일 09:00 – 18:00`의 운영 시간을 수정합니다.
5. 변경한 파일을 저장하고 GitHub에 커밋·푸시하면 사이트에 자동 반영됩니다.

`피아노숨결`이라는 상호와 서비스 문구도 같은 파일에서 자유롭게 바꿀 수 있습니다.

## GitHub Pages 켜기

이 저장소에는 `main` 브랜치에 변경 사항이 올라올 때 사이트를 배포하는 GitHub Actions 워크플로가 포함되어 있습니다.

1. GitHub 저장소에서 **Settings** → **Pages**로 이동합니다.
2. **Build and deployment**의 **Source**를 **GitHub Actions**로 선택합니다.
3. `main`에 푸시한 뒤 **Actions** 탭에서 `Deploy static site to GitHub Pages` 작업이 성공할 때까지 기다립니다.
4. 완료 후 Pages 설정 화면에 표시되는 주소에서 사이트를 확인합니다.

이 저장소의 기본 주소 형식은 `https://poianopks.github.io/iano-tuning-test/` 입니다.
